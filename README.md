# Consultoría para la Provisión de Software - PyME y BDP

![Estado del Proyecto](https://img.shields.io/badge/Estado-En_Desarrollo-yellow)

Este repositorio contiene la documentación técnica y estratégica para la implementación de una solución de software orientada a la gestión financiera de PyMEs, diseñada específicamente para el **Banco de Desarrollo Productivo (BDP)**.

## 🎯 Objetivo del Proyecto
Optimizar la recolección de datos en campo por parte de los asesores mediante una aplicación móvil robusta, segura y capaz de funcionar en entornos sin conexión (Offline-first).

* **Metodología:** DevOps para integración y despliegue continuo.
* **Interfaz:** Basada en los estándares visuales oficiales del BDP.
